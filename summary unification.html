Mechanism Design via the Adjoint Functor Theorem

A Lean 4 / Mathlib Formalization of Myerson (1981) and Mirrlees (1971)
Formalization · 2026  ·  Branch: master

Overview

This project formalizes the insight that two classical results in mechanism design — Myerson's Revenue Equivalence Theorem and the Mirrlees Taxation Principle — are corollaries of a single abstract categorical theorem: the forgetful functor Q from incentive-compatible mechanisms to allocation rules has a right adjoint T, the transfer functor.

The construction is carried out in Lean 4 with Mathlib. The five source files progress from abstract categorical infrastructure (Framework.lean) through the adjunction proof (MasterTheorem.lean) to the two economic instantiations (MyersonSetting.lean, MirrleesSetting.lean) and their corollaries (Corollaries.lean).

Categorical Structure

Economic Primitives

Definition — Mechanism

A direct mechanism over allocation space A is a pair m = (q, t) where q : ℝ → A assigns an allocation to each type, and t : ℝ → ℝ is the transfer (payment by agent). Utility is v(q(θ), θ) − t(θ) — quasilinear in the transfer (condition QI).

Definition — Single Crossing (SC)

For a domain D ⊆ ℝ, the value function v : A → ℝ → ℝ satisfies SC on D if for every a > a′ in A, the surplus difference θ ↦ v(a,θ) − v(a′,θ) is strictly increasing on D.

def SingleCrossing {A : Type*} [Preorder A] (v : A → ℝ → ℝ) (D : Set ℝ) : Prop :=
  ∀ (a a' : A), a > a' → StrictMonoOn (fun θ => v a θ - v a' θ) D
Definition — IsIC / IsIR

IC (Incentive Compatibility) restricted to types ≥ θ_min: truth-telling weakly dominates any misreport θ′.

IR (Individual Rationality): the lowest type θ_min obtains non-negative surplus — normalised to V(θ_min) = v(q(θ_min), θ_min) − t(θ_min) ≥ 0.

def IsIC (v : A → ℝ → ℝ) (θ_min : ℝ) (m : Mechanism A) : Prop :=
  ∀ θ θ' : ℝ, θ_min ≤ θ → θ_min ≤ θ' →
    v (m.q θ) θ - m.t θ ≥ v (m.q θ') θ - m.t θ'

Key Lemmas and Theorems

Lemma 1.7 — IC_implies_monotone
IC + SC ⟹ MON

Every BIC mechanism with a single-crossing value function has a non-decreasing allocation rule on [θ_min, ∞). Proof: if q were decreasing on some interval, higher types could profitably mimic lower types, contradicting IC.

Assumptions: SC, IC (and transitively QI).
Conclusion: MonotoneOn m.mech.q (Set.Ici θ_min)

Lemma 4.2 — T_wellDefined
T(r) is BIC-IR for any monotone allocation r

Given any monotone allocation rule r : ℝ → A, the mechanism T(r) = (r.q, t*) with transfer formula t*(θ) = v(r.q(θ), θ) − ∫θ_minθ (∂v/∂s)(r.q(s), s) ds is BIC and IR.

Additional assumptions: 0 < θ_min, SC, v(a,·) differentiable on (0,∞), integrability of typeDerivAlongAlloc.

Theorem 4.3 — adj_Q_T
Q ⊣ T (The Adjunction)

The forgetful functor Q : Mech → Alloc has a right adjoint T : Alloc → Mech. The adjunction is constructed via unit η and counit ε:

  • Unit η_m : m → T(Q(m)): proved via FTC + IR boundary condition
  • Counit ε_r : Q(T(r)) → r: allocation equality is definitional
  • Triangle identities: immediate from the subsingleton property of Hom-sets

Additional assumptions: hEnv (envelope derivative holds for each mechanism), 0 < θ_min.

Theorem 4.5(ii) — masterTheorem_isomorphism
Every BIC-IR mechanism with allocation r is isomorphic to T(r)

If m is BIC-IR with allocation rule r (i.e. m ∈ MechWithAlloc r), and the envelope derivative holds pointwise, then m ≅ T(r) in Mech.

Key assumptions: hEnv₁ (FTC envelope for m), hBC (binding IR: v(q(θ_min),θ_min) = t(θ_min)).

Theorem 4.5(iii) — masterTheorem_transferInvariance
Same allocation + binding IR ⟹ same expected transfer

If m₁ and m₂ are both BIC-IR with the same allocation rule r and the same boundary value V(θ_min) = 0, then ∫ t₁ dμ = ∫ t₂ dμ for any finite measure μ.

Proof: by 4.5(ii), m₁ ≅ T(r) ≅ m₂, so t₁ = t₂ pointwise (on [θ_min,∞)). A non-physical sorry remains for θ < θ_min.

QI structural Utility = v(q(θ),θ) − t(θ); linearity in t baked into Mechanism No wealth effects. A euro transferred has the same marginal value regardless of the agent's wealth. Equivalently, money and the allocation are separable in utility. Without QI, the trade-off between allocation and payment depends on the agent's type, entangling the two components and breaking the revenue equivalence argument (Maskin–Riley 1984). All theorems

In taxation: a higher-ability worker benefits more from supplying extra income. SC is the ordering condition that makes the revelation principle give a monotone allocation; without it IC no longer implies MON and the envelope theorem fails. In Myerson, a bidder with value 0 is indifferent and adds no economic content. Technically this ensures differentiability of v(a,·) on (0,∞) so the FTC applies. hMono economic Monotone mech.q — allocation non-decreasing in type Efficient discrimination: better types receive weakly better allocations. This is a necessary condition for IC under SC — if a higher type received a strictly worse allocation, they could profitably mimic a lower type (IC_implies_monotone). hintC analytic IntervalIntegrable (deriv (v a)) μ b c for all a, b, c The marginal type-value is integrable for each fixed allocation. For any fixed allocation level a, the derivative ∂v(a,θ)/∂θ is integrable. This is needed for the IC-implies-envelope direction: comparing utility under truthful and mimicking reports requires integrating the marginal value over the type interval. hEnv analytic HasDerivAt (fun s ↦ v(r.q s, s) − t s) (typeDerivAlongAlloc v r θ) θ for θ > 0 The first-order condition of IC holds: V′(θ) = ∂v/∂θ(q(θ),θ). This is the envelope theorem — a truthful agent at type θ cannot gain by a marginal type perturbation, so the surplus derivative equals the direct type-effect of the value function. In Myerson: V′(θ) = q(θ). In Mirrlees: V′(θ) equals the Spence-Mirrlees cross-partial. This is the key condition that pins down the transfer formula uniquely. adj_Q_T (unit), T_terminal, masterTheorem_isomorphism
hBC economic v(m.q θ_min, θ_min) = m.t θ_min — binding IR at the boundary The designer extracts all surplus from the lowest type. V(θ_min) = 0: the marginal bidder or worker is left with exactly zero rent. This is the standard "participation constraint binds at the bottom" normalization. It fixes the integration constant in the envelope formula, making the transfer schedule unique. Two mechanisms with the same allocation but different boundary values produce different expected revenues. masterTheorem_isomorphism, masterTheorem_transferInvariance
hD_Ioi analytic Set.Ioi 0 ⊆ D — SC domain contains (0,∞) The type ordering is globally consistent across all positive types. SC must hold on the entire physical domain, not just locally. This ensures that the revelation principle produces a globally monotone allocation, not merely locally non-decreasing. T_wellDefined, masterTheorem_*
A : AddCommGroup categorical Allocation space has additive group structure Allocation differences are well-defined. The spread Δ(θ) = q′(θ) − q(θ) between two allocation rules must be meaningful. In auctions A = ℝ corresponds to probability differences; in taxation to income differences. The spread-monotonicity condition on morphisms (h_spread) requires subtraction, which needs the group structure. MechHom, AllocHom, T functor on morphisms (T.map)
A : LinearOrder categorical Total order on allocations Allocations can be unambiguously ranked. Needed for the mimicry argument: if q(θ₂) < q(θ₁) for θ₂ > θ₁, type θ₂ can profitably pretend to be θ₁ (since they strictly prefer the higher allocation under SC), contradicting IC. In auctions and taxation A = ℝ provides a canonical total order on probabilities or income levels. IC_implies_monotone, masterTheorem_*

Economic Corollaries

Corollary 5.1 — Revenue Equivalence (Myerson 1981)

Setting: A = ℝ, v(q,θ) = θ·q (linear-in-allocation), θ_min > 0.

Any two BIC-IR mechanisms with the same allocation rule q₀ and binding IR at θ_min have the same expected revenue under any finite measure μ:

𝔼μ[t₁(θ)] = 𝔼μ[t₂(θ)]

Proof: instantiate masterTheorem_transferInvariance with myerson_singleCrossing and myerson_vDiff. One-liner.

Reference: Myerson (1981) Theorem 2; Riley–Samuelson (1981).

Corollary 5.2 — Taxation Principle (Mirrlees 1971)

Setting: A = ℝ, v(y,θ) = θ·h(y) − g(y/θ) (Spence-Mirrlees), θ_min > 0.

Any two IC mechanisms with the same income assignment y(θ) and the same V(θ_min) produce identical transfer schedules — hence the same expected tax revenue:

𝔼μ[t₁] = 𝔼μ[t₂]

Proof: instantiate masterTheorem_transferInvariance with mirrlees_singleCrossing and mirrlees_vDiff.

Reference: Hammond (1979) Thm 1; Rochet (1985) Prop 1.

Definition — Envelope Transfer Formula

The unique transfer consistent with IC, IR, and boundary condition V(θ_min) = 0:

t*(θ) = v(q(θ), θ) − ∫θ_minθ (∂v/∂s)(q(s), s) ds

In the Myerson setting: t*(θ) = θ·q(θ) − ∫θ_minθ q(s) ds
In the Mirrlees setting: t*(θ) = v(y(θ),θ) − ∫θ_minθ (∂v/∂s)(y(s),s) ds

Instantiation Comparison

Remaining Sorry and Design Limitations

Sorry — T.map.hTransf (MasterTheorem.lean:259) — vacuous

Status: mathematically false for general v, but never exercised.
The field hTransf in T.map f would require T(r).t θ ≤ T(r′).t θ whenever r.q θ ≤ r′.q θ — an inequality that holds in the Myerson case (v linear in a) but is false for general v. However, this field is never accessed by any proved theorem: the functor laws (map_id, map_comp) are discharged by mechHom_subsingleton, and the hTransf used in masterTheorem_transferInvariance is constructed independently via FTC + IR (MasterTheorem.lean:398–415), not through T.map. Removing it would require adding a v-monotonicity hypothesis to T that does not hold for general v.

Failure conditions (formal stubs)
  • Non-QI: without quasilinearity, Q no longer factors through Alloc; the adjunction breaks and revenue equivalence fails (Maskin–Riley 1984).
  • Multi-dimensional types: no total order on ℝᵏ for k ≥ 2; the completeness argument for Alloc fails and the Adjoint Functor Theorem does not directly apply (Rochet 1987; Armstrong 1996).
  • Non-regular (ironing): without the regularity condition the optimal allocation is non-monotone; ironing (concavification) is required and uniqueness of T(q) recovers only in expectation (Myerson 1981 §6; Ebert 1992).

Recent Extensions

Mirrlees Monotonicity (MirrleesSetting.lean)

Under the envelope formula and positive partial derivative ∂v/∂θ > 0:

  • mirrlees_strictMono_rent: information rent V(θ) = ∫ ∂v/∂s ds is strictly increasing — higher-ability workers earn strictly more surplus.
  • mirrlees_strictMono_utility: equilibrium utility is strictly increasing in type — a direct consequence of the envelope theorem.
  • mirrlees_strictMono_alloc: income assignment y(θ) is strictly increasing — higher ability implies higher gross earnings.
  • mirrlees_strictMono_consumption: consumption c(θ) = y(θ) − T(y(θ)) is strictly increasing when T′ < 1 — a sub-unitary marginal tax rate is the condition that no worker faces a 100% effective tax rate.
N-Bidder BIC → Reduced-Form IC (MyersonSetting.lean §2.7)

Full formalization of Myerson's reduced-form approach for n-bidder auctions using Measure.pi μ product measures:

  • expAllocN: Qi(s) = ∫ p(t−i, s) i ∂Πjμj — the reduced-form winning probability for bidder i at type s, integrating over all opponents' types using Function.update t i s.
  • IsBICN: joint Bayes-IC condition on the full product-measure integral — truthful reporting is optimal in expectation over opponents.
  • expAllocN_satisfies_IC: IsBICN → IsMultiAgentIC for the reduced-form functions. Proof is purely algebraic (integral linearity via integral_sub + integral_const_mul); no Fubini needed.

Key design choice: Function.update t i s fixes bidder i's type at s in the full profile t : Fin n → ℝ, avoiding Fin(n−1) arithmetic entirely.
